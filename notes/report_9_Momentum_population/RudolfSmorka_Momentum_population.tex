\section{Aim}
The aim of this document is to understand the voltage-dependence of the steady-state momentum-space population. 

Milestones:
\begin{itemize}
	\item Simulate a simple TB model
	\begin{itemize}
		\item Plot the voltage-dependent nonequilibrium momentum-space population (one can use LB for this)
		\item Investigate the differences from the equilibrium Fermi distribution
	\end{itemize}
	\item Simulate a TB model with molecular vibrations within Ehrenfest approximation
	\begin{itemize}
		\item Make the same plots as in the first milestone
	\end{itemize}
	\item Simulate an effective model having the same DOS as the one for the 	vibrational model with equilibrium vibrations
	\begin{itemize}
		\item Show sample-averaged DOS, and compute energy-dependent coupling function
		\item Feed these quantities (discretized in energy-space) into LB formulas, and compare to Ehrenfest approach
	\end{itemize}	
\end{itemize}
